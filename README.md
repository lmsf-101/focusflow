# FocusFlow

![status](https://img.shields.io/badge/status-en%20desarrollo-yellow)

Aplicación realizada con TS + React + Python que sirve como un gestion de tareas con un Pomodoro "flexible" que busca adaptar sesiones de trabajo efectivas según la tarea / contexto en cuestión, y apoyar al usuario en lograr sus objetivos de forma medible.

### Stack tecnológico

- Typescript + React
- Vite
- Python >=3.13 + FastAPI
- PostgreSQL

### Estructura del repositorio

`backend/` -> Manejo de lógica y datos para la aplicación, mediante Python

`frontend/` -> Código de interfaz del usuario y componentes, mediante Typescript + React


### Arquitectura

Hoy corre en local con Docker Compose (frontend, backend y PostgreSQL). El destino planeado es AWS.
